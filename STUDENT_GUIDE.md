# 🎓 Student Quick Start Guide

## Welcome to Bottle WiFi Vendo! 🌍

This guide will help you get started with the eco-friendly WiFi vending system.

## What You Need

- Your Student ID
- Plastic bottles to recycle
- A computer or terminal to access the system

## Getting Started

### Step 1: Registration
Register yourself in the system with your student ID:
```bash
python3 cli.py
# Select option 1 (Register New Student)
# Enter your student ID and name
```

### Step 2: Collect Bottles ♻️
Bring your plastic bottles to any collection point and:
```bash
python3 cli.py
# Select option 2 (Login)
# Select option 3 (Collect Bottles)
# Enter the number of bottles you're bringing
```

### Step 3: Get WiFi Access 🎟️
Exchange your bottles for WiFi vouchers:
```bash
python3 cli.py
# Select option 4 (Get WiFi Voucher)
# Choose your preferred duration
# Save your voucher code!
```

### Step 4: Activate WiFi
Use your voucher code to activate WiFi on the campus network.

## Frequently Asked Questions

### Q: What types of bottles can I bring?
A: All plastic bottles (water, soda, juice, etc.) are accepted!

### Q: Do I need to clean the bottles?
A: Yes, please rinse them out. Clean bottles are easier to recycle!

### Q: How long are vouchers valid?
A: Vouchers expire 30 days after creation, so use them!

### Q: Can I transfer bottles to a friend?
A: Currently, bottles are tied to your account and cannot be transferred.

### Q: What happens to the bottles?
A: All bottles are properly recycled, reducing plastic waste and saving CO2 emissions!
